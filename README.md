# charlottecvn.github.io

Personal academic site: research, publications, talks, teaching and CV.

## Publish on GitHub Pages
1. Create a public repo named `<your-github-username>.github.io`.
2. Upload `index.html`, `photo.jpg` and `.nojekyll` to the repo root (or `git push`).
3. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
4. The site appears at `https://<your-github-username>.github.io` within a minute or two.

## Editing
Everything is in `index.html` (no build step). Add a paper by copying one `<li>` inside `<ul class="pubs">`.
